# DQN 주식 매매 논문 작성 방향과 자료 구성

작성 기준: 실험 1~30의 기록과 실험 21·28·29·30의 저장 결과. 핵심 정량 비교는 동일한 5개 시드와 3개 검증 구간을 사용한 결과를 대상으로 한다. 이 문서는 논문 기획안이며 새로운 성능 검증을 수행한 결과는 아니다.

## 1. 추천 주제

**거래비용을 고려한 DQN 기반 주식 비중 조절의 수익률과 시드 민감도 분석: 삼성전자 walk-forward 사례 연구**

영문 가제: *Returns and Seed Sensitivity of DQN-Based Stock Allocation with Transaction Costs: A Walk-Forward Case Study of Samsung Electronics*

중심 질문은 "최고 수익률이 나온 단일 학습 결과가 여러 시드와 검증 연도에서도 유지되는가?"로 잡는다. 은닉층 너비, 행동 공간의 세분화, Double DQN 변경을 비교하고, 수익률·위험·거래 강도·시드 편차의 관계를 설명한다.

현재 자료는 단일 종목의 탐색적 실증 연구에 적합하다. 새 강화학습 알고리즘 제안, 모든 시장에서의 초과수익, DQN 또는 DDQN의 일반적 우월성을 주장할 근거는 아직 부족하다. 목표 학회나 학술지에 따라 독창성·추가 검증 수준은 별도로 조정한다.

## 2. 연구 질문과 대응 실험

| 연구 질문 | 활용 실험 | 현재 관찰 | 논문에서의 역할 |
|---|---|---|---|
| 단일 시드 최고 성과는 여러 시드에서도 유지되는가? | 20 → 21 | 검증 평균 65.90%였던 설정의 5개 시드 평균은 51.76%, 시드 표준편차는 12.40%p | 여러 시드를 사용해야 하는 동기 |
| 은닉층 너비가 시드 민감도에 어떤 영향을 주는가? | 21 ↔ 28 | hidden_dim 128과 256의 검증 평균은 비슷하지만 표준편차는 12.40%p와 1.65%p | 중심 비교 |
| 행동을 3개에서 5개로 늘리면 어떤 변화가 나타나는가? | 28 ↔ 30 | 평균 검증 수익률과 회전율은 개선, 시드 편차와 약한 구간 성과는 악화 | 행동 공간 분석 |

| 관찰된 장점은 어느 연도에 집중되는가? | 28의 15개 결과 | 2024 검증에서는 모든 시드가 B&H 상회, 2023·2025에서는 모든 시드가 B&H 하회 | 시장 상황별 한계 분석 |

실험 20은 실험 21과 별개의 다중 시드 설정이 아니다. 실험 21은 실험 20 설정을 5개 시드로 반복한 결과이며 시드 42 결과가 실험 20에 해당한다. 이를 독립적인 성과 두 개로 집계하지 않는다.

## 3. 본문 핵심 비교표

다음 값은 선택된 검증 체크포인트에 대한 개발 단계 결과다. 모든 설정은 시드 1, 7, 21, 42, 100과 검증 연도 2023, 2024, 2025를 사용했다.

| 설정 | 알고리즘 | 은닉층 너비 | 행동 수 | 평균 검증 수익률 | 시드 표준편차 | 평균 검증 MDD | 평균 검증 회전율 |
|---|---|---:|---:|---:|---:|---:|---:|

| 실험 28 | DQN | 256 | 3 | 51.00% | 1.65%p | 11.08% | 56.706 |

| 실험 30 | DQN | 256 | 5 | 53.19% | 3.69%p | 10.61% | 46.673 |

같은 세 검증 연도의 B&H 수익률 산술평균은 45.54%다. 실험 28이 모든 지표의 최고값을 갖는 것은 아니다. 시드 민감도가 낮은 기준 후보로 설명하고, 어떤 지표를 중요하게 보아 선택했는지 명시한다. 수익률과 표준편차를 합친 새 점수를 결과를 본 뒤 만들어 최적임을 주장하지 않는다.

실험 21·28·29·30의 저장된 15개 실행 모두에서 실험별 원시 OHLCV 해시는 한 종류이며, 네 실험 간에도 같은 해시다. 시드 42/val2025 설정 파일을 비교하면 실험 28 대비 차이는 각각 hidden_dim, algorithm, action.values다. 다만 실험 21과 28은 manifest에 기록된 main.py 해시가 다르다. 원래 코드 스냅샷에서 차이를 확인하거나 동일하게 고정한 코드에서 재현하기 전까지 완전한 코드 동일성을 주장하지 않는다. 이 비교에서 다른 주요 학습·환경·피처 모듈의 기록 해시는 일치했다.

2026 결과는 아래처럼 별도로 제시한다. 같은 기간을 여러 번 살펴본 기록이 있으므로 독립성을 보장한 최종 시험으로 표현하지 않는다.

| 설정 | 2026 평균 수익률 | 2026 시드 표준편차 | 평균 테스트 MDD |
|---|---:|---:|---:|
| 실험 21 | 99.46% | 51.47%p | 36.80% |

수익률과 MDD는 저장된 결과를 그대로 사용한다. B&H도 동일 체결 시점과 비용 가정을 따른다. MDD 열은 각 실행 MDD의 산술평균이며 하나로 연결한 자산곡선의 MDD가 아니다.

## 4. 연도별로 보여줄 핵심 결과

| 검증 연도 | 실험 28 시드 평균 | B&H | 실험 28의 연도 내 시드 표준편차 |
|---|---:|---:|---:|
| 2023 | 34.78% | 41.39% | 6.14%p |
| 2024 | 7.75% | -31.76% | 2.44%p |
| 2025 | 110.47% | 126.99% | 4.28%p |

핵심 해석은 "선택된 검증 모델들의 상대 성과가 2024 하락 연도에서 특히 높았으며, 2023·2025 상승 연도에서는 B&H보다 낮았다"이다. 현재 자료만으로 모든 하락장에서 수익을 보장하거나 일반적인 시장 상황 적응 능력이 입증됐다고 쓰지 않는다. 연도 구분은 관찰 결과의 설명이며 사전에 정의된 시장 국면 분류기는 아니다.

검증 3개 연도에서 매번 다른 학습 모델을 평가했기 때문에 이 수익률을 곱해 실제 하나의 전략이 벌어들인 3년 누적수익률로 제시하면 안 된다. 사후 선택된 검증 구간의 자산곡선을 이어 붙여 실전 성과로 해석하지 않는다.

## 5. 방법론에 반드시 적을 내용

| 항목 | 실험 28 기준 |
|---|---|
| 자산과 주기 | 삼성전자 005930, KIS 일별 OHLCV |
| 요청 데이터 범위 | 2018-01-01~2026-09-11 |
| 실제 첫 학습 거래일 | 피처 준비 및 관찰창 이후 2018-07-26 |
| 상태 | 시장 피처 15개 × 최근 20거래일 + 현재 주식 비중 1개, 총 301차원 |
| 신경망 | 입력 301 → 256 → 256 → 행동별 Q값 3개, 은닉층 ReLU |
| 행동 | 목표 주식 비중 0%, 50%, 100%; 현금과 단일 종목 사이 배분 |
| 시간 순서 | t일 종가 정보 관찰 → t+1일 시가 체결 → t+1일 종가 평가 |
| 보상 | 비용 반영 자산의 일별 로그수익률 |
| 비용 가정 | 매수·매도 수수료 각각 0.015%, 매도 세금 0.25% |
| 투자 제약 | 초기자금 1,000만 원, 정수 주식, 공매도·레버리지 없음, 최소보유일 0 |
| 주요 설정 | Huber, Adam, lr=0.001, gamma=0.99, batch=32, replay=20,000 |
| 학습 | 100에피소드, learning_starts=256, 학습 500회마다 타깃 복사 |
| 탐험 | epsilon 1.0 → 최소 0.05, 학습 업데이트마다 0.999배 |
| 체크포인트 선택 | 각 폴드의 validation 누적수익률 최고 에피소드 |
| 평가 | 탐험 없이 argmax, 가중치 갱신 없음, 끝의 보유 주식은 종가 평가 |

비용 수치는 구현된 고정 가정이다. 해당 기간 실제 세율·수수료를 모두 정확히 재현했다고 주장하지 않는다. 시가에 정해진 목표 비중대로 거래되는 일별 체결 모형이며, 호가 스프레드·슬리피지·시장충격은 현재 별도 모형이 없다. 배당 현금흐름도 별도로 처리하지 않으므로 주가 기반 결과임을 밝히고 데이터 공급자의 수정주가 설정과 기업행동 처리를 확인한다.

### 데이터 분할

| 폴드 | 실제 학습 체결 기간 | validation 체결 기간 |
|---|---|---|
| val2023 | 2018-07-26~2022-12-29 | 2023-01-02~2023-12-28 |
| val2024 | 2018-07-26~2023-12-28 | 2024-01-02~2024-12-30 |
| val2025 | 2018-07-26~2024-12-30 | 2025-01-02~2025-12-30 |

2026 평가에는 val2025에서 선택한 각 시드의 체크포인트를 사용한다. 기간은 2026-01-02~2026-09-11, 총 171거래일이다. 초기 관찰창이 앞 구간에서 이어지는 것은 당시 이미 알려진 과거 정보의 사용이다.

초기 두 폴드의 저장된 test는 각각 2024~2026, 2025~2026으로 중복된다. 이 test 세 개를 독립적인 세 번의 외부 검증으로 평균하지 않는다. 현재 구성은 expanding-window validation을 통한 설정 탐색으로 명명하는 것이 정확하다.

## 6. 지표 표기와 과장 방지

| 항목 | 논문에서 사용할 정확한 정의 |
|---|---|
| 평균 validation 수익률 51.00% | 각 시드의 3개 폴드 수익률 산술평균을 다시 5개 시드에 대해 평균한 값 |
| 시드 표준편차 1.65%p | 위의 시드별 폴드 평균 5개에 대한 표본 표준편차, ddof=1 |
| 평균 worst validation 7.75% | 각 시드의 최저 폴드 수익률을 구한 뒤 5개를 평균한 값 |
| 전체 최저 validation 4.31% | 실험 28의 15개 시드·폴드 결과 중 최솟값 |
| 에피소드 변동성 15.25%p | 폴드별 100에피소드 validation 수익률 표준편차의 평균; 시드 표준편차와 다름 |
| Sharpe | 일별 초과수익 평균/표본 표준편차 × sqrt(252), 무위험수익률 가정 0 |
| MDD | 해당 실행의 자산 최고점 대비 최대 하락률, 손실 크기를 양수로 표시 |
| Turnover | 매 거래의 절대 체결금액/거래 직전 시가 평가 자산을 기간 전체에 걸쳐 합산한 값 |

회전율 56.706은 비율의 합인 무차원 누적값이며 56.706%가 아니다. 연환산한 값도 아니다. 길이가 다른 연도와 171일 테스트의 회전율을 그대로 비교해 거래가 줄었다고 단정하지 않는다.

"시드 표준편차가 1.65%p이므로 학습과 실전이 모두 안정적"이라는 표현은 피한다. 폴드 평균을 내는 과정에서 연도별 차이가 상쇄될 수 있으므로 연도별 시드 분포도 함께 보여준다.

시드 42를 대표 매매 사례로 보여줄 수는 있지만, 그 하나의 2026 수익률 117.72%를 실험 28의 대표 성능처럼 쓰면 안 된다. 주 결과는 5개 시드 전체이고, 최고 시드는 사례 분석으로 표시한다. 현금 기준선의 Sharpe가 정의되지 않는 경우 0으로 임의 변환하지 않고 N/A로 표시한다.

## 9. 제출 전에 우선 보완할 실험

1. **동일한 고정 코드에서 핵심 비교 재현.** 실험 21·28·29·30의 설정, 데이터 스냅샷, 시드, 선택 규칙을 고정한다. 새로운 시드를 더 쓰면 기존 5개도 포함해 전부 보고한다. 계산 예산이 가능하면 총 10~20개 시드로 불확실성을 더 확인하되, 시드만 늘려도 검증 선택 편향이 사라지는 것은 아니다.
2. **기준선 강화.** 현재 cash와 B&H에 더해 매 거래일 주식 50%/현금 50%로 조절하는 고정비중 전략과 미리 정한 단순 이동평균 전략을 추가한다. 똑같은 다음 날 시가, 정수 주식, 비용 가정을 적용한다. 낮은 MDD가 단순히 현금 비중 때문에 생기는지 구분하는 데 중요하다.
3. **새로운 최종 평가 절차 고정.** 2026 결과를 열람한 이력과 실제 선택 근거를 구분해 기록한다. 현재까지 관찰한 구간은 탐색적 OOS로 표기하고, 계획을 고정한 뒤 아직 관찰하지 않은 미래 구간에서 forward 평가한다. 날짜를 소급해서 지정하거나 기존 구간을 다시 돌리는 것만으로 미관측 시험이 되지 않는다.
4. **거래 마찰 민감도.** 동일 정책을 사전에 정한 슬리피지·비용 시나리오에서 평가한다. 설정을 비용 시나리오별로 다시 학습하는 실험과 고정 정책의 비용 민감도를 구분한다. 현재 수수료·세금의 기간별 현실성도 점검한다.
5. **적용 범위 확장.** 다른 종목이나 지수에서 고정된 설정을 평가한다. 대상은 성과를 보기 전에 정한다. 종목별 재학습과 한 종목 모델의 직접 전이를 별도 질문으로 구분한다.

새 시드나 새 자산을 평가한 결과로 다시 설정을 고르면 해당 자료 역시 개발에 사용한 자료가 된다. 독립적인 최종 시험의 범위를 미리 적고 유지한다.

각 폴드의 최고 validation 에피소드를 보고하는 것은 모델 선택 과정이다. 그 최고값들의 평균을 편향 없는 미래 성능 추정이라고 부르지 않는다. 더 엄격한 성능 비교가 필요하면 학습 구간 내부에 체크포인트 선택용 validation을 두고, 다음 외부 구간에서는 고정된 선택 결과만 평가하는 nested walk-forward를 사전에 설계한다. 기존에 열람한 외부 구간을 다시 분할하더라도 완전히 새 데이터가 생기는 것은 아니다.

15개 결과는 동일한 한 종목과 서로 겹치는 학습 이력에서 나온다. 이를 독립 표본 15개로 단순 t-test하지 않는다. 같은 시드·같은 평가 구간의 짝 비교를 하고, 시드 변동과 시장 시계열의 불확실성을 따로 설명한다. 시계열 bootstrap을 적용한다면 일별 자기상관을 고려한 블록 단위를 사용하고, 이미 수행한 모델 선택 편향까지 자동으로 해결되는 것처럼 표현하지 않는다.

## 10. 권장 목차

1. 서론: 단일 최고 수익률 중심 평가의 한계, 비용과 재현성 문제, 본 연구 질문.
2. 관련 연구: DQN, Double DQN, 금융 강화학습 환경, 다중 시드 평가와 백테스트 선택 편향.
3. 방법: 상태·행동·보상, 신경망, 주문 시점, 비용, 기준선, 평가 지표.
4. 실험 설계: 초기 탐색과 핵심 다중 시드 비교 구분, 날짜 분할, 선택 규칙, 재현 자료.
5. 결과: 단일 시드와 다중 시드의 차이, 너비 비교, 행동 수 비교, DDQN 비교, 연도별 결과.
6. 논의: 상승 연도 참여와 하락 연도 결과의 차이, validation과 2026 진단의 간극, 단일 종목·선택 편향·체결 가정의 한계.
7. 결론: 해당 설정과 데이터에서 관찰된 관계, 아직 일반화할 수 없는 범위, 사전 고정한 후속 평가.

원고의 중심 문장 예시:

> 동일한 다섯 시드와 세 검증 연도를 사용한 비교에서, 은닉층 너비 256인 DQN은 너비 128인 설정과 유사한 평균 검증 수익률을 보이면서 시드별 폴드 평균 수익률의 표준편차가 작게 관찰되었다. 행동 공간 세분화와 Double DQN 변경은 평균 검증 수익률을 높였으나 위험 및 시드 민감도에 대한 효과는 일관되지 않았다. 이미 관찰한 2026 평가 구간에서는 모든 비교 설정의 평균 수익률이 매수 후 보유 전략에 미달하였다.

이 문장은 관찰 결과의 요약이다. 통계적으로 우월성이 입증됐다는 주장이나 새 데이터에 대한 예측을 포함하지 않는다.

## 12. 확인한 원논문과 인용 위치

1. **Mnih et al. (2015), Human-level control through deep reinforcement learning, Nature.** DQN의 경험 재생과 타깃 네트워크를 소개하는 알고리즘 배경에 사용한다. 주식 수익률 개선의 근거로 인용하지 않는다. [원논문](https://www.nature.com/articles/nature14236)
2. **van Hasselt, Guez, Silver (2016), Deep Reinforcement Learning with Double Q-learning, AAAI; arXiv preprint 2015.** 행동 선택과 평가 분리를 통한 과대평가 완화의 이론적 동기에 사용한다. 현재 프로젝트에서 Q값 과대평가가 감소했다고 주장하려면 Q값과 후속 할인보상의 별도 측정이 필요하다. [원논문](https://arxiv.org/abs/1509.06461)
3. **Henderson et al. (2018), Deep Reinforcement Learning that Matters, AAAI.** 무작위성·실험 보고·재현성 문제와 다중 시드 평가 동기에 사용한다. [학회 논문](https://ojs.aaai.org/index.php/AAAI/article/download/11694/11553)
4. **Agarwal et al. (2021), Deep Reinforcement Learning at the Edge of the Statistical Precipice, NeurIPS.** 소수 반복의 점추정 한계와 구간 추정 등 평가 방법을 논의할 때 사용한다. 이 연구의 여러 벤치마크 평가를 단일 금융 시계열에 그대로 적용했다고 쓰지 않는다. [원논문](https://arxiv.org/abs/2108.13264)
5. **Liu et al. (2020), FinRL: A Deep Reinforcement Learning Library for Automated Stock Trading in Quantitative Finance, NeurIPS Deep RL Workshop.** 금융 거래 환경, 비용 제약, 재현 가능한 파이프라인 관련 연구에 사용한다. FinRL을 사용하지 않은 자체 구현이면 그 차이를 명시한다. [원논문](https://arxiv.org/abs/2011.09607)
6. **Bailey, Borwein, López de Prado, Zhu, The Probability of Backtest Overfitting, 2015 revised manuscript.** 여러 전략·설정 탐색에 따른 선택 편향과 백테스트 과적합의 한계를 설명할 때 사용한다. 현재 연구에서 해당 논문의 PBO를 계산한 것은 아니다. 최종 참고문헌 양식에는 인용할 출판본의 연도·권호를 확인해 넣는다. [저자 공개 원고](https://www.davidhbailey.com/dhbpapers/backtest-prob.pdf)

## 13. 작성 순서

1. 방법과 실험 설계를 먼저 적고 날짜·지표 정의를 고정한다.
2. 핵심 네 설정의 표와 15개 검증 결과를 본문·부록에 배치한다.
3. 평균뿐 아니라 개별 시드와 연도별 결과를 확인하며 결과 절을 쓴다.
4. 보완 실험을 진행했다면 탐색 결과와 분리해 추가한다.
5. 결론이 실제 자료보다 강하지 않은지 점검한 뒤 서론·초록·제목을 마무리한다.

실험 28을 반드시 우승시키는 서술보다, 단일 최고 성과와 재현 가능한 성과가 어떻게 다른지 보여주는 서술이 현재 자료와 가장 잘 맞는다.
